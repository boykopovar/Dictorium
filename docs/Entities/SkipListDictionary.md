# SkipListDictionary

`SkipListDictionary<TKey, TValue>` — упорядоченный словарь на основе **skip list** (списка с пропусками). Структура хранит пары ключ–значение на основе нескольких параллельных упорядоченных списков.

Реализация наследует `IDictionary<TKey, TValue>` и поддерживает обход пар через `begin()` / `end()` (уровень 0).

---

## Сложности операций

| Метод | O (верхняя граница) | Ω (нижняя граница, ожидаемая) | Амортизированная | Пояснение |
|-------|---------------------|-------------------------------|------------------|-----------|
| `ContainsKey` | O(n) | Ω(log n) | O(log n) | Один проход `_search`: спуск с уровня `_level` до 0, на каждом уровне — сдвиг по `forward[level]` пока `next->key < key`. В среднем ~log₂ n уровней и ~1 шаг на уровень |
| `TryGetValue` | O(n) | Ω(log n) | O(log n) | `_search`; при успехе копирует `value` |
| `GetValue` | O(n) | Ω(log n) | O(log n) | `_search` + доступ к полю; при отсутствии ключа выбрасывает исключение |
| `InsertOrAssign` (ключ есть) | O(n) | Ω(log n) | O(log n) | `_search` с заполнением пути предшественников; если элемент отсутсвует, то вставка на `_randomLevel()`
| `Add` | O(n) | Ω(log n) | O(log n) | Один `_search`; при дубликате — `std::invalid_argument`, иначе вставка как в `InsertOrAssign` |
| `Remove` | O(n) | Ω(log n) | O(log n) | `_search` + `_unlinkNode` на всех уровнях узла + возврат в freelist |
| `Clear` | O(n) | Ω(n) | O(n) | Очистка пула `_pool`, сброс `_head`, `_count` |
| `Count` | O(1) | Ω(1) | O(1) | Возврат поля `_count` |
| `initializer_list` / конструктор диапазона | O(n²) | Ω(n log n) | O(n log n) | `initializer_list` вызывает `Add` на каждую пару (два прохода при дубликатах невозможны). Конструктор `(first, last)` — `InsertOrAssign`|
| Итерация (`begin` / `end`) | O(n) | Ω(n) | O(n) | Линейный проход по уровню 0 (`forward[0]`) |
| `operator[]` (из `IDictionary`) | O(n) | Ω(log n) | O(log n) | Делегирует в `GetValue` / `InsertOrAssign` |

> **Обозначения:** n — число элементов в словаре; p — `DTR_SKIPLIST_P` (вероятность поднять уровень, по умолчанию 0.5).

> Верхняя граница **O(n²)** для `initializer_list` через `Add` достигается только при патологическом сценарии; при n уникальных ключах фактически **O(n log n)** в среднем.

> **Худший случай O(n):** если случайные высоты «не помогают» (все узлы на уровне 0 или вырожденное распределение), поиск деградирует до линейного списка. При p = 0.5 и ограничении `DTR_SKIPLIST_MAX_LEVEL = 32` вероятность такого события на больших n пренебрежимо мала.

## Устройство списка

### Уровни

| Уровень | Содержимое | «Пропуск» элементов |
|---------|------------|---------------------|
| 0 | Все ключи по возрастанию | Нет (шаг 1) |
| 1 | Случайное подмножество уровня 0 | В среднем ~половина узлов |
| 2 | Подмножество уровня 1 | В среднем ~четверть узлов уровня 0 |
| k | … | Между соседними ссылками на уровне k в среднем ~2ᵏ узлов уровня 0 |

Фиксированного числа «пропускаемых ячеек» **нет**: высота каждого узла задаётся `_randomLevel()` (геометрическое распределение с параметром p).

## Примеры использования

```cpp
#include "Dictorium/Dictorium.h"

using namespace dtr;

int main() {
    SkipListDictionary<std::string, int> dict = {
        {"beta", 2},
        {"alpha", 1},
        {"gamma", 3},
    };

    dict.InsertOrAssign("delta", 4);
    std::cout << dict["alpha"] << '\n';  // 1

    if (dict.ContainsKey("gamma")) {
        std::cout << "found\n";
    }

    for (const auto& [key, value] : dict) {
        std::cout << key << ": " << value << '\n';
    }

    dict.Remove("beta");
    std::cout << dict;
}
```

## Итог

`SkipListDictionary` — вероятностный упорядоченный словарь с **ожидаемым O(log n)** на основные операции и **O(n)** на обход. Подходит для изучения упрощенной альтернативы сбалансированным деревьям.

Платой за простоту кода относительно AVL-дерьев являются вероятностные гарантии и более высокие константы на практике по сравнению с `std::map`.
