# Dictorium

Dictorium - это C++ библиотека, посвящённая реализации и исследованию **алгоритмов поиска элементов по ключу**.

## Реализованные структуры

### 1. Алгоритмы поиска по первичному ключу и индексные структуры в СУБД

- [AvlDictionary](docs/Entities/AvlDictionary.md)
- [RedBlackTreeDictionary](docs/Entities/RedBlackTreeDictionary.md)


### 2. Гарантированно константное время доступа

- [PerfectHashDictionary](docs/Entities/PerfectHashDictionary.md)
- [CuckooHashDictionary](docs/Entities/CuckooHashDictionary.md)

### 3. Хеш-таблицы.

- [ChainingHashDictionary](docs/Entities/ChainingHashDictionary.md)
- [LinearProbingDictionary](docs/Entities/LinearProbingDictionary.md)
- [QuadraticProbingDictionary](docs/Entities/QuadraticProbingDictionary.md)
- [DoubleHashDictionary](docs/Entities/DoubleHashDictionary.md)
- [RobinHoodHashDictionary](docs/Entities/RobinHoodHashDictionary.md)


### 4. Вероятностные структуры

- [SkipListDictionary](docs/Entities/SkipListDictionary.md)
- [TreapDictionary](docs/Entities/TreapDictionary.md)

Реализованные классы и интерфейсы находятся в пространстве имен `dtr`.
